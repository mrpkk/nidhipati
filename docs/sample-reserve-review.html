Sample: “Example RWA Issuer” (synthetic)

The issuer’s public page says: “Each EXUSD token is backed 1:1 by US Treasury bills and cash, attested monthly by an independent auditor.” It publishes a PDF with a total reserve and a link to the auditor’s letter. This is what the review returns.

Verdict

A buyer can verify the total, not the backing. The page answers “how much” and leaves “what exactly, from where, as of when, and can I check it” unanswered.

This is not a claim that the reserves are wrong. It is a statement about what the public page proves.

Fix list (3 steps)

  1. Publish one dated JSON with one row per reserve line: asset, quantity, price source, haircut, as-of.
  2. Add token supply or liabilities at the same timestamp, and a named data owner.
  3. Sign the file and publish the public key; a buyer runs one command and sees backed, underbacked, or incomplete.
