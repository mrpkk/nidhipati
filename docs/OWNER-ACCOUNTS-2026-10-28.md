- Что будет после: агент публикует пакет, появляется `pip install attest-receipt` и страница на pypi.org.

- Имя свободно: **`attest-receipt`** (проверено 28.10).
- Время: 2 мин.

### A3. Docker Hub — образ для тех, кто разворачивает сам

- Что сделать: аккаунт → https://hub.docker.com/settings/security → «New Access Token» (Read & Write).
- Время: 2 мин.
