What you get

  • Signed JSON attestation — reserve lines, liabilities/supply, NAV, verdict, source hashes, and the public key. The buyer verifies it without trusting our server.
  • Human-readable report — the same numbers with the arithmetic shown: what backs the token, which lines carry a haircut, and what could not be priced.
  • Fail-closed behaviour — if one reserve line has no price, the report says incomplete and does not print a backing ratio. It does not guess.
  • Privacy by construction — the report carries the minimum needed to recompute NAV. Full wallets, counterparties, and strategy stay out unless you choose to include them.
  • Offline verification pack — the public key, a one-command check, and a short note your buyer or auditor can keep.

What we need from you

Data

  • Reserve lines: asset, quantity, price source, haircut, as-of date.
  • Liabilities or token supply for the same date.
  • Custodian or issuer sign-off on the source data — one named owner.
  • NDA if the data is private. We work from a read-only export; no private keys, no custody, no wallet access.

Decisions

  • Which asset and date are in scope.
  • Whether the report is public or buyer-only.
  • Whether your name and the numbers may appear in an anonymized case study. If not, the standard price applies and nothing is published.
  • One written contact for questions. No calls required.

How it runs

  1. Scope (same day). You confirm the asset, date, and whether the data is private. We confirm price and the one named data owner in writing.
  2. Intake (1–2 days). You send the reserve and liability export. We check that every row has a source and a price. Missing rows are named, not filled.
  3. Build (3–5 days). We compute NAV and the backing ratio, sign the report, and write the human-readable version. You see a draft before it is final.
  4. Verification (1–2 days). We verify the signed file with the published key on a clean machine and send you the exact command.
  5. Delivery (10 working days). Final JSON, report, public key, and verification note. One retest of agreed corrections is included.

Verification guarantee

If the signed report does not verify offline with the published key, the fee is refunded. This is a statement about the file and the signature — not about the issuer’s solvency, the accuracy of its source data, or the value of the asset.

What this is not

Not a statutory audit, legal opinion, or investment advice. We do not custody funds, issue a token, or guarantee repayment. The issuer remains responsible for the truth of the source data. The report says what was checked, what was not, and which line failed — it does not say “100% safe”.
