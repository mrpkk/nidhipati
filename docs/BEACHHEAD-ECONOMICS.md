# Beachhead economics — Nidhipati vs Soma (26.10.2026)

**Вопрос:** как выбор beachhead влияет на доход?  
**Ответ коротко:** Nidhipati даёт чек в 25–50 раз больше с одного клиента и не требует интеграции. Soma — стратегический протокол, но near-term revenue через Mitra Core требует десятков подписок и внешней интеграции. Поэтому текущее решение — **Nidhipati beachhead, Soma поддержка** — максимизирует вероятность первого платежа.

---

## 1. Цены и единица дохода

| Продукт | Единица | Цена | Что нужно клиенту |
|---|---|---:|---|
| **Nidhipati** | аудит | **$1,250** первые 3, затем **$2,500** | принести записи; без интеграции |
| Nidhipati retainer | месяц | **$1,500/мес** | после аудита |
| Nidhipati savings | % | **20%** подтверждённой экономии | после аудита |
| **Soma protocol** | — | **$0** (MIT) | интеграция/соответствие |
| **Mitra Core** | среда/мес | **$49/мес** | интеграция движков |
| Mitra Core x402 | вызов | **$0.005** | техническая интеграция |

**Вывод:** один аудит Nidhipati = **26–51** подписок Mitra Core по $49. Один retainer $1,500 = **30** подписок.

---

## 2. Сколько клиентов нужно до $10k

| Сценарий | Нужно | Реалистичность near-term |
|---|---:|---|
| Nidhipati, первые 3 по $1,250 | **8 аудитов** | 8 клиентов; каждый — отдельный разговор |
| Nidhipati, после первых 3 по $2,500 | **4 аудита** | 4 клиента |
| Nidhipati, 4 аудита + 2 ретейнера | **4 + 2** | $10k + $3k/мес |
| Mitra Core по $49/мес | **204 среды** | 204 интеграции/подписки |
| Mitra Core, $10k MRR | **204 активных** | требует дистрибуции и удержания |

**Вывод:** до $10k Nidhipati нужно **4–8 продаж**, Soma/Mitra Core — **~204 подписки**. Это разные игры.

---

## 3. Воронка и цикл сделки

### Nidhipati

```
100 целевых визитов → 10 бесплатных сканов → 2 платных аудита (20%)
2 аудита × $2,500 = $5,000
```

Допущение: 20% конверсия скан → аудит. Это **гипотеза**, не факт. Но даже при 10% нужно 20 сканов на 2 аудита.

- Продажа: written, без звонка.
- Интеграция: не нужна.
- Доказательство: отчёт по их CSV + кейс.
- Платёж: USDC/банк; карта — потом.

### Soma / Mitra Core

```
100 разработчиков → 10 интеграций → 1–2 платящих среды
1–2 × $49/мес = $49–98/мес
```

- Продажа: техническая интеграция.
- Нужен внешний implementation, прошедший conformance.
- Доказательство: benchmark/репутация/партнёр.
- Платёж: подписка/инвойс; карта не решена.

**Вывод:** Soma требует **в 10–100 раз больше клиентов** для того же дохода и более длинный цикл.

---

## 4. Что это значит для дохода

| Фактор | Nidhipati | Soma/Mitra Core |
|---|---|---|
| Чек | высокий | низкий |
| Клиентов до $10k | 4–8 | ~204 |
| Интеграция | не нужна | нужна |
| Время до первого платежа | короче | дольше |
| Доказательство | один отчёт/кейс | conformance + партнёр |
| Риск | нет трафика/кейса | нет внешней реализации |
| Стратегическая ценность | средняя | высокая |

**Итог:** Nidhipati — про **быстрый первый платёж**; Soma — про **протокол и долгосрочную позицию**. Держать Soma как beachhead сейчас = отложить доход и всё равно упереться в трафик/платёж.

---

## 5. Когда менять решение

Пересмотреть beachhead, если:

1. Nidhipati не даёт **5 сканов / 1 платёж** за 30 дней.
2. Появится **design partner** для Mitra Core с оплатой пилота.
3. Soma PR #17341 merged и даёт измеримый трафик, которого хватает на интеграции.
4. Владелец решит, что стратегический протокол важнее near-term выручки.

До этого — **Nidhipati beachhead, Soma поддержка**.

---

## 6. Честные ограничения

- 20% конверсия — гипотеза, не измерение. Проверять на 5 сканах.
- $49/мес Mitra Core — опубликованная цена, но платящих 0.
- Soma protocol MIT не приносит выручку напрямую.
- Ни один сценарий не учитывает стоимость трафика: бюджета нет, каналы органические.
